Malformed date caveat

Dates are stored as dd-MM-yyyy keyword strings with an explicit format on the date fields. A value that does not match the pattern is not silently coerced — date range queries and histograms simply exclude it. Treat the histograms as coverage of well-formed dates, not a completeness guarantee.

P13 Administrative Runbook (Documented Only)

The following operations require cluster admin privileges and are intentionally not exposed by this read-only application:

  • Security & Users: Create / manage native users, roles, and role mappings (e.g. POST /_security/user/...).
  • API Keys: Generate, invalidate, and rotate cluster/index API keys (POST /_security/api_key).
  • Slow Logs: Adjust index search and indexing slow-log thresholds via PUT /{index}/_settings.
  • Snapshots: Register snapshot repositories (S3 / shared filesystem), trigger snapshots, and restore indices.
  • Replication & Routing: Change index.number_of_replicas to 0 to turn a single-node cluster green, or assign replicas across multiple nodes.
